# Mirror Slime 1.0.0 — First Public Playtest Release! 🌈

**Created by Chase Johnson**

After extensive design, balancing, and playtesting, the complete **Mirror Slime** Yu-Gi-Oh! custom archetype is ready for other duelists to try in **MDPro4**.

This fan-made 20-card set includes:

- Six differently attributed Mirror Slimes.
- King Rainbow Slime, a Fusion Monster that becomes stronger depending on which Attributes you use.
- Queen Rainbow Slime, Prism Slime Knight, and the Pure/Inversion Pendulum pair.
- A full lineup of themed Spell and Trap support.
- Original custom card artwork, scripted effects, and a ready-to-play 40-card Main Deck with a nine-card Extra Deck.

### Download

Download **`Mirror_Slime_v1.0.0.ypk`** from this repository. In MDPro4, go to **Settings → Expansions → Download Custom Card Pack** and paste the file's **Raw GitHub URL**.

The pack has been playtested on MDPro4 v1.0.4 for Windows with a local bot. Other clients and devices are not yet fully tested, so please share any bugs, card interactions, or balance feedback through GitHub Issues.

Happy dueling, and thanks for giving the Mirror Slimes a try! 👑🌈
