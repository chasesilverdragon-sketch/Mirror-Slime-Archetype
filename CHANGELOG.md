# Changelog

## v1.0.0 — First public playtest release

Built from the **v40** locally tested Mirror Slime pack.

- Includes all 20 playable cards, artwork, Lua effects, and the 40-card Main Deck / nine-card Extra Deck profile.
- Finalized King Rainbow Slime's Fusion procedure: three to six differently attributed Mirror Slime materials, with additional Attribute-based benefits.
- Added King's working effect selection: **Banish 1 card**, **Reduce ATK**, or **Use both effects**.
- Preserved the distinction between King's non-targeting banish and Blue's targeting ATK reduction.
- Corrected card effect display for the Pendulum Monsters.
- Refined Mirror Slime – Brown's DEF increase.
- Restored Mirror Slime – Purple's separate Graveyard-send and Fusion-material destruction effects, excluding Fusion-material sends from the Graveyard-send trigger.
- Corrected various activation windows, effect-selection freezes, and custom card pack compatibility issues during the private test versions.
- Confirmed the pack against local MDPro4/WindBot testing; wider device and client compatibility remains unverified.

Earlier development packs were numbered v1–v40 for debugging. Public release numbering begins at **v1.0.0**.
